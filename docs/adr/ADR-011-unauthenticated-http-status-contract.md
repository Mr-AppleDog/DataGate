# ADR-011：未认证请求的 HTTP 状态码契约

- 状态：已确认
- 日期：2026-08-30
- 关联：Issue #1；RES-006；docs/05 §3.1

## 背景

未认证请求经过 Sa-Token 异常处理器时，统一响应体已经返回业务码 401，但响应未同步设置 HTTP 传输状态，导致客户端收到 HTTP 200。该行为不符合 `docs/05` 的接口契约，也会让调用方误判认证状态。

## 决策

1. `SaTokenExceptionHandler.handleNotLoginException` 在返回统一响应前，将 `HttpServletResponse` 状态设置为 401。
2. 保持现有统一响应体的业务码和非泄露提示不变；本修复不增加资源名称、凭据或查询结果的返回内容。
3. 回归测试同时断言 HTTP 传输状态和统一响应体，避免只修复其中一层。

## 影响与边界

- 仅修正未认证请求的 HTTP 传输语义，不放宽任何权限判定或资源访问。
- 不涉及数据库迁移、会话存储、凭据处理或前端行为。
- 如需回滚，撤销实现提交即可；无需数据恢复操作。
