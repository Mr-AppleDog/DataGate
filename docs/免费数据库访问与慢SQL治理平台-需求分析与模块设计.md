# 免费数据库访问与慢 SQL 治理平台

本文件是交付入口。项目已从早期单篇概念稿升级为可实施的完整规格集，后续开发、评审和验收以 [数据库访问治理平台规格/00-文档索引与项目基线.md](数据库访问治理平台规格/00-文档索引与项目基线.md) 为唯一基线。

## 已确认基线

- 公司内部单组织，面向全体员工，不做公开多租户 SaaS；
- 本地账号起步，管理员创建，无公开注册，正式上线启用 TOTP；
- P0 支持 MySQL、PostgreSQL、Redis/Tair；
- 按实例、库、Schema、表，以及 Redis DB/Key 前缀/命令类别授权；
- 生产查询默认只读，导出和 DML/DDL/Redis 写操作独立授权并审批；
- 平台托管查询、变更、监控三类账号，用户无法获得数据库密码；
- 支持查询审计、慢查询采集、钉钉/邮件/Webhook 告警和治理闭环；
- 基于 RuoYi-Vue-Plus v5.6.2、Java 17、Spring Boot 3.5.15；
- 生产最小双应用节点；容量按 1,000 用户、300 数据源、50 并发查询设计；
- 目标 RPO 15 分钟、RTO 1 小时。
